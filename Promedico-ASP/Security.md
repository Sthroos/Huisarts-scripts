# Security Policy

## Meldpunt
Meld een kwetsbaarheid, bug, of ander probleem via:
- E-mail: info@huisartseneemland.nl
- Of: open een GitHub pull request of issue op deze repository

Iedereen mag een melding of pull request insturen.

## Reactietermijn
Meldingen worden zo snel mogelijk opgepakt. De afhandelingstermijn hangt
af van de ernst van het probleem.

## Scope
Deze extensie draait in de page-context van promedico-asp.nl, zorgdomein.nl en
zneller.nl en heeft toegang tot patiëntgegevens zoals die in het EPD getoond
worden. Kwetsbaarheden die deze toegang vergroten of omzeilen vallen binnen
scope.

## Bekende architecturale beperkingen
Zie `Privacy.md` §2 (DEV-XPI sideload-kanaal) — niet gebruiken op werkstations
met actieve patiëntdossiers.
