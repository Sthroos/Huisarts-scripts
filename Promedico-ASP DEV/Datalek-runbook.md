# Datalek-procedure (Art. 33-34 AVG, 72-uurs termijn)

1. Melding komt binnen bij deze Github of via info@huisartseneemland.nl.
2. Impact-inschatting: welke patiëntgegevens, hoeveel praktijken, welk script
   betrokken is.
3. Melding aan de Autoriteit Persoonsgegevens loopt via Huisartsen Eemland —
   niet via de extensie-ontwikkelaar. De ontwikkelaar levert de technische
   feiten aan Eemland aan.
4. Communicatie richting aangesloten praktijken via Eemland.
5. Post-mortem en fix-release.
